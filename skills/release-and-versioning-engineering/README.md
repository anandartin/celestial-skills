# Release and versioning

A Celestial engineering skill — how the product is built and shipped.

## What's inside
- `SKILL.md`
- `AGENTS.md`
- `rules/release-and-versioning-engineering.mdc`
- `README.md`

## Use it
- **Claude Code** — put the `release-and-versioning-engineering` folder in `~/.claude/skills/` (all projects) or `.claude/skills/` in a repo. Claude uses it whenever a request fits.
- **Claude (claude.ai)** — Settings → Capabilities → Skills → Upload skill, and choose a .zip of this folder. Or add `SKILL.md` to a Project's knowledge.
- **ChatGPT, Gemini and other assistants** — attach `SKILL.md` (and the other files) to the chat or a custom GPT / Gem, or paste the text of `SKILL.md`, then ask, e.g. “Make a 10-slide deck in this brand.”
- **Codex, Copilot, Cursor** — copy `AGENTS.md` to your repo root, `release-and-versioning-engineering/SKILL.md` to `.github/skills/release-and-versioning-engineering/`, and `rules/release-and-versioning-engineering.mdc` to `.cursor/rules/`.
